# 🚀 Featured Projects

## 🤟 SignBridge — AI-Powered Sign Language Communication for Healthcare

**Team Lead & AI Developer — Huawei Türkiye R&D Center**

A privacy-first application designed to help deaf patients communicate
with healthcare professionals using Turkish Sign Language.

**Tech:** Python • MediaPipe • Bidirectional GRU • Computer Vision • FastAPI • Next.js

- Led a **3-person development team** during the Huawei ICT Talent Internship.
- Designed and developed the AI recognition pipeline end-to-end.
- Camera video remains on-device while extracted landmark coordinates are processed.
- Expanded the recognition vocabulary from **20 to 34 sign classes**.
- Improved AUTSL-20 test accuracy from **85.2% to 92.1%**.
- Designed safety mechanisms including quality checks, confidence thresholds,
  vocabulary restrictions and patient confirmation.
- Conducted generalisation and ablation experiments for unseen signers.
